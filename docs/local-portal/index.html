n8n is optional. It only starts with the n8n profile:
.\scripts\local-dev.ps1 n8n   or   docker compose -f docker-compose.local.yml --profile n8n up -d
Quick commands (PowerShell):
.\scripts\local-dev.ps1 infra — start postgres + redis + this portal
.\scripts\local-dev.ps1 up — build + start full stack
.\scripts\local-dev.ps1 smoke — run smoke tests
.\scripts\local-dev.ps1 urls — print all URLs
.\scripts\local-dev.ps1 reset — wipe volumes & restart
